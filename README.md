This repository contains all the code used to complete the project, even small tests such as in small_tests. In some code files you may see a 'dissertation DLC content' folder referenced, which contains additional files such as PDFs and any files downloaded from the internet. It is named as such in reference to video games, where DLC stands for 'downloadable content', which is additional content created for the base game. That's the story.

The full pipeline is called full_ner_pipeline.ipynb, and combines everything, so that may be a good place to start looking.
